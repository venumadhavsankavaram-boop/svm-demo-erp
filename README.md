# Sunrise Public School — demo ERP (SVM EdTech)

A separate, self-contained demo of the school ERP, with a fictional school and sample data.
It is NOT connected to any real school: own GitHub repo, own GoDaddy project, own database.

- `erp/` — the ERP (same code as the real school's ERP, plus demo mode and the sample-data script)
- `erp/demo/DEMO-SETUP.md` — environment variables and how the sample data loads
- `erp/demo/seed-demo.mjs` — builds the sample school (wipes only a demo/empty database)

Website: to be added as `website/` (rebranded to Sunrise Public School).
