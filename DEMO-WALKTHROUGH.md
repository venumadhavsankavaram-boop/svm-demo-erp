# Demo walkthrough (Sunrise Public School)

All logins use the password shown on the sign-in page (default `Demo@123`). Data reloads every night at 02:00 IST.

| Login | Show this |
|---|---|
| demo.principal / demo.admin | **Admin Tools → Teacher portal**: switch teacher features on/off, choose approve-first or auto-approve, attendance/marks edit windows, what teachers can see (then sign in as demo.teacher to show the effect). Manage Exams: FA1 (marks released) and FA2 (dates set, upcoming). Release tab, Admit Cards, Room Allotment. Exam plans waiting for review (English), online exam waiting for approval (English quiz). Admit Cards: fee hold is ON (dues above ₹500); one student is already "Allowed" with a reason on record. |
| demo.teacher ("Demo Teacher") | **Teacher portal**: greeting banner, big task tiles (English / Telugu), phone bottom bar. Class teacher of 5th Class A; teaches Telugu, English, Maths, EVS there and Maths in 6th and 8th. Exam Plans, Online Exams, Study Material, Homework, Attendance for 5th A. |
| demo.student / demo.parent | 5th Class A. FA1 marks card (released), FA2 exam plan, Maths quiz (can be taken live), study material, homework, timetable, fee balance and the "pay fee to get the hall ticket" message. |
| demo.accountant / demo.office | Fees, receipts, accounting, inventory, library. |
| demo.branch | North Campus accountant (section B of classes 1–5). |

Not pre-filled on purpose (do it live): generating hall tickets and room allotment for FA2, marking attendance, taking the online quiz as the student, releasing FA2 marks after entering them.
